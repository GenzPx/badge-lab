# Catatan Belajar Git

## Alur kerja dasar
1. `git checkout -b nama-branch` — bikin branch baru
2. edit file
3. `git add .` dan `git commit -m "pesan"`
4. `git push -u origin nama-branch`
5. Buka Pull Request, review, lalu merge

## Kenapa pakai branch?
Supaya perubahan yang belum selesai tidak mengganggu branch utama.
